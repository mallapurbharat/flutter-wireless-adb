Forks and derivative works **may** truthfully state that they are based on this
project, for example:

> "Based on Flutter Wireless ADB by Bharat Mallapur."

This kind of factual, nominative reference is always allowed.

## Publishing a modified version

If you publish a modified version as a **separate extension** (for example, to a
marketplace), you **must use a clearly different name** and your own branding.
You may still include the truthful attribution line shown above.

For any use beyond truthful attribution, please obtain written permission from
the original authors.
